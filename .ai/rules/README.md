# Правила работы в этом репозитории

Не описание подсистем — это в [docs/](../docs/README.md), — а то, как здесь
принято работать. Каждое правило появилось из конкретной ошибки, и у каждого
написано, из какой: правило без причины через полгода выглядит произволом, и
его обходят.

| Файл | О чём |
|---|---|
| [docs-references.md](docs-references.md) | Как ссылаться на код из документации |
| [code-changes.md](code-changes.md) | Удаление кода и правки схемы БД |
| [experiments.md](experiments.md) | Что обнуляет накопленную статистику и как не отравить отбор |

Читать целиком не нужно — они короткие, но нужны в разные моменты. Перед
правкой документации хватит первого, перед удалением кода или миграцией —
второго, перед изменением логики ботов — третьего.
