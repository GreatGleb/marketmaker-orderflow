# Тестовые боты (test bots) — документация для ИИ-агентов

Подсистема бумажной торговли (paper trading): симулирует тысячи вариантов
торговой стратегии на живых ценах Binance, не отправляя ни одного реального
ордера. Результат каждой симулированной сделки пишется в `test_orders`, по
ним считается прибыльность конфигураций.

Все пути в документации — от корня репозитория
(`/home/greatgleb/PycharmProjects/marketmaker-orderflow`).

## Точка входа в 30 секунд

```
general/app/scripts/start_test_bots.py     ← процесс, который надо запускать
    └── StartTestBotsCommand               ← general/app/bots/demo_test_bot.py:48
            └── simulate_bot()             ← general/app/bots/demo_test_bot.py:434
                    └── redis LPUSH "order_queue"
                            └── OrderBulkInsertCommand → INSERT INTO test_orders
```

Симулятор **не пишет в БД напрямую** — только в очередь Redis. За вставку
отвечает отдельный процесс. Симулятор **не читает конфиги ботов из БД
повторно** — снимок берётся один раз на старте (кроме копиботов).

## Главное, что нужно знать перед правкой

1. `demo_test_bot.py` — «горячий» цикл: `asyncio.sleep(0.1)` × N активных
   ботов. Любой лишний запрос в БД внутри цикла выхода убивает
   производительность.
2. Симулятор бесполезен без питателя цен: `price:{SYMBOL}` в Redis. Нет
   ключа — `PriceProvider.get_price` висит вечно и молча.
3. **Сделки в `test_orders` старше 2026-08-26 непригодны для анализа.**
   До этой даты действовал баг, из-за которого любая сделка закрывалась
   через 30 секунд, так и не дойдя до своих TP/SL. Подробности и остальные
   ловушки — [08-gotchas.md](08-gotchas.md).
4. **Сырые сделки живут 72 часа**, дальше от них остаются только свёртки с
   шагом в десять минут. Анализ по отдельным сделкам надо успевать делать
   в этом окне либо выгружать данные — [10-retention.md](10-retention.md).
