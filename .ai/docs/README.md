# Документация для ИИ-агентов

Здесь — только документация по подсистемам проекта. Остальное содержимое
`.ai/` (промпты, конфиги, скрипты агентов и т.п.) живёт рядом, вне `docs/`.

Одна подсистема = одна папка с собственным `README.md`-индексом.

| Папка | Подсистема |
|---|---|
| [test-bots/](test-bots/README.md) | Тестовые боты (paper trading): `start_test_bots` + `demo_test_bot` и их зависимости |

Незакрытые задачи по тестовым ботам собраны в
[test-bots/09-roadmap.md](test-bots/09-roadmap.md) — новую сессию удобно
начинать оттуда.

Предложение по разделению стратегий и подготовке стратегии 0:
[план рефакторинга](test-bots/12-multi-strategy-plan.md).

## Соглашения

* Все пути в документах — от корня репозитория
  (`general/app/bots/demo_test_bot.py`).
* Ссылки на код — **якорем, а не номером строки**: имя функции, поля,
  константы или дословный фрагмент кода. Правило и причины —
  [../rules/docs-references.md](../rules/docs-references.md).
* В старых разделах номера строк ещё встречаются. Они устаревают молча и
  начинают показывать на чужой код, поэтому сверяйтесь с якорем, а
  встреченные номера переводите на якоря по мере правки раздела.

Остальные правила работы в репозитории — [../rules/](../rules/README.md).
